# 2026-06-12 08:43 — UI redesign: modern, intuitive, user-friendly

**Request:** "Redesign the UI to make it more user friendly and look better" /
"more beautiful, intuitive, modern, and user friendly".

**Current state:** stock Qt widgets, no theme, no icons, no menus. Analyser
side panel is a pile of 10 stacked text buttons; Recorder crams 12 controls
into one row; plot toolbar is unstyled text glyph buttons; QCustomPlot is
default white regardless of any theme.

## Plan

1. **New `style/` static lib (`scope_style`)** — single place for look & feel:
   - `Theme`: Fusion base + crafted light/dark `QPalette` + one token-driven
     QSS sheet (tabs, buttons w/ `accent`/`danger` variants, inputs, item
     views, headers, splitters, slim scrollbars, menus, tooltips, status
     pills, section labels). `ThemeMode {System, Light, Dark}` persisted in
     QSettings; System resolves via `QStyleHints::colorScheme()` (Qt 6.9).
   - `StyleKit`: crisp QPainter-drawn icons (no asset files, DPI-aware,
     theme-neutral gray + accent/record colors): app logo, tab icons
     (record dot / waveform / convert arrows), plus/minus/pencil, folder,
     save, refresh, plug. Helpers: `sectionLabel()`, status-pill setter,
     `installEmptyHint(view, text)` overlay for empty tables/trees/lists.

2. **ShellWindow / main**: menu bar (File: Exit; View: Appearance
   System/Light/Dark; Help: "Plot mouse & keyboard controls" cheat-sheet
   dialog + About), window icon, tab icons, status bar with live
   "Store: N channels", geometry + last-tab + theme persistence.
   `main.cpp` gains an env-guarded offscreen screenshot hook
   (`SCOPE_SHELL_SCREENSHOT_DIR`) + demo signals for visual verification.

3. **ScopePlot**: fully palette-driven (background, axes, grid, legend,
   crosshair, measure overlay), separate axis color palettes for light/dark,
   re-styles itself on `QEvent::PaletteChange` and emits
   `themePaletteChanged()` so hosts re-derive channel pens. Flat hoverable
   toolbar in a framed strip.

4. **Analyser tab**: file/layout actions move to a top action bar
   (Open/Save chart · Save/Load layout · spacer · accent Redraw).
   Left panel becomes sectioned: VIEW / CHANNELS (header row with +/✎/−
   icon buttons) / table with per-channel color swatches / Y AXES (+/−).
   Panel sits in a real splitter (no hard 320px cap). Same sectioning for
   the Recorder live-preview sidebar.

5. **Recorder tab**: split the single crammed row into a Connection row
   (source, ADS fields, Connect/Disconnect, status pill) and a Capture row
   (prominent ● Record / ■ Stop, live stats). Record disabled until
   connected. Section labels + empty-state hints on symbol browser and
   channel table.

6. **Converter tab**: toolbar grouped with separators + icons, section
   labels, empty hint on file list, pill-style status.

7. Build linux-release (incl. relink of app target per project memory),
   run scope_tests, then offscreen screenshots of all 3 tabs × both themes;
   iterate until it actually looks good.

**Non-goals:** no behavior/logic changes, no PLC-side anything, no new
dependencies (icons are painted, not shipped), AddChannelDialog and other
dialogs inherit the global theme only.
